# Bakery Inventory System

The Bakery Inventory System is a Python-based application designed to help a small bakery
manage ingredient stock levels efficiently. The system allows tracking of ingredients,
quantities, and updates, supporting basic inventory management operations.

This project demonstrates fundamental programming concepts and practical problem-solving
using Python.

## Technologies
- Python

## Features
- Add new ingredients to inventory
- Update ingredient quantities
- Remove ingredients
- View current stock levels
- Simple menu-driven interface

## Skills Demonstrated
- Dictionaries and lists for data storage
- Functions and modular program design
- Input validation
- Control flow (loops and conditionals)

## Use Case
Designed for small businesses such as bakeries to manage ingredient inventory
in a simple and lightweight manner.

## Purpose
Academic project developed to demonstrate Python programming fundamentals,
data handling, and basic inventory system logic.
